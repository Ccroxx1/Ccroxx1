### 🎵 GlassPlayer

A modern Android music player built with Jetpack Compose.

**Highlights:**

- 🎵 Local music library
- 🔎 Music search
- 📂 Folder browsing
- 📑 Playlists
- ▶️ Background playback
- 🎚️ Equalizer
- ⏱️ Sleep timer
- 🎨 Glassmorphism-inspired interface
- 🎧 Media3 / ExoPlayer playback
